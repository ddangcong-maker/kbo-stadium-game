# KBO Stadium Social — channel-enabled 3D MVP

모바일 브라우저에서 실행하는 초기 3D 야구장 소셜 게임 프로토타입입니다.

## 이번 버전에 반영된 내용
- 채널당 최대 100명, 최대 10개 채널(이론상 총 1,000명)
- 접속 시 빈자리가 있는 가장 앞 채널에 자동 입장
- 화면 상단 채널 선택 메뉴로 채널 이동
- 채널별 아바타/실시간 위치/채팅 분리
- 금칙어는 메시지 차단 대신 해당 부분을 `****`로 치환
- 터치 이동 및 드래그 카메라 회전
- 간단한 3D 경기장, 1층/3층 보기, 앉기/응원/음식 동작

## 실행
Node.js 18 이상에서:

```bash
npm install
npm start
```

브라우저에서 `http://localhost:3000` 접속. 같은 서버 주소에 접속한 여러 브라우저/기기가 같은 채널에서 서로 보입니다.

## 배포 전 반드시 알아둘 점
- 이 프로젝트는 개발용 MVP이며 공개 서비스/상용 운영 준비가 끝난 상태가 아닙니다.
- 채널은 서버 프로세스 하나 안에서 나뉩니다. 1,000명 동시 접속을 보장하지 않으며 부하 테스트와 서버 증설이 필요합니다.
- 여러 서버 인스턴스로 확장하려면 Socket.IO Redis 어댑터, 공통 채널 카운터/배정, 인증·보안·속도 제한 등을 추가해야 합니다.
- 현재 1층/3층 버튼은 완성된 계단 경로 이동이 아닌 테스트용 층 전환입니다.
- 상점 구매/음식 애니메이션, 실제 응원단 로테이션, 음원/공간 음향, 캐릭터 커스터마이징, NPC 경기, 저장 기능은 후속 개발 항목입니다.
- Three.js는 CDN에서 불러오므로 인터넷 연결이 필요합니다.
